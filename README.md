# Python Practice
 
A consolidated collection of small Python practice projects — CLI games, algorithm drills, and daily coding exercises. Each subfolder is a self-contained project; see its own README for details.
 
## 🎮 Games
| Project | Description |
|---|---|
| [games/password-guessing](games/password-guessing) | CLI password guessing game with difficulty levels and smart feedback (correct/misplaced/wrong characters) |
| [games/slot-machine](games/slot-machine) | Python slot machine with betting, multipliers, bonus rewards, and free spins |
| [games/quiz-game](games/quiz-game) | Quiz game that scores the user based on their answers |
| [games/number-guessing](games/number-guessing) | Basic number guessing game (C) |
| [games/timed-math-quiz](games/timed-math-quiz) | Timed math quiz for practicing quick arithmetic under time pressure |
 
## 📅 Daily Practice
| Project | Description |
|---|---|
| [daily-practice](daily-practice) | Daily-solved Python practice questions, organized by topic (strings, recursion, OOP, etc.) |
 
## 🗂️ Misc
| Project | Description |
|---|---|
| [misc/fake-news-generator](misc/fake-news-generator) | Tool to generate, modify, and save fake news data for practice purposes |
 
## Why This Repo Exists
These were originally separate repos. They've been consolidated here since each was a small, single-purpose script — keeping them together makes the practice history easier to browse and keeps the main profile focused on larger, more substantial projects.
 
## Running a Project
Each subfolder is independent. `cd` into it and run per its own README — most are:
```bash
cd games/<project-name>
python main.py
```
